# Multi-Dataset Data Transformation

## Overview

This BAN130 group project uses Python and pandas to clean, filter, transform, and format multiple SAS datasets.

My primary contribution was Part 1, which involved:

- Loading and inspecting EU occupancy data
- Decoding SAS text fields
- Filtering records from 2016
- Formatting accommodation values
- Removing unnecessary columns

Other project sections included National Park data transformation, customer-data queries, credit-score classification, and marital-status classification.

## Tools

Python · pandas · NumPy · Matplotlib · SAS data

## Data Availability

The original datasets are not included because of file-size, privacy, and academic-use considerations. The notebook retains its code and saved outputs for portfolio review.

## Project Type

Completed as a five-member academic group project.
